# 📦 DICT24 - Group Project (Inventory Module)

Nandito sa repository na ito ang files para sa part ko sa ating web development group project. Sundin lang ang mga steps sa ibaba para makuha at mabuksan ang project sa PC ninyo.

---

## 📥 Step 1: Paano I-download ang Project

1. Mag-scroll paitaas sa page na ito.
2. I-click ang green na **`<> Code`** button sa bandang kanan.
3. Piliin ang **`Download ZIP`** sa pinakababa ng dropdown menu.
4. Hintaying matapos ma-download ang **`INVENTORY`** ZIP file.

---

## 📂 Step 2: Paano I-extract ang Files

### Sa Windows 10 / 11:
1. Buksan ang **File Explorer** at pumunta sa **Downloads** folder.
2. Hanapin ang **`INVENTORY.zip`**.
3. **I-right-click** ang file at piliin ang **`Extract All...`** (o *Extract Here* kung may WinRAR / 7-Zip ka).
4. Piliin kung saang folder mo gustong i-save (halimbawa: Desktop) at i-click ang **`Extract`**.

### Sa Mac:
1. Pumunta sa **Downloads** folder sa Finder.
2. **I-double-click** lang ang **`INVENTORY.zip`** at kusa na itong gagawa ng extracted folder.

---

## 💻 Step 3: Paano Buksan ang Project

1. Buksan ang na-extract na **`INVENTORY`** folder.
2. I-double-click ang **`index.html`** para ma-preview sa browser, o i-open ang buong folder sa **VS Code** para ma-edit.
